# Audio assets

Every audio file under `apps/web/src/audio/` has a row here: where it came from and under what license. Each file stays under 500 KB (ARCHITECTURE.md 2.7). Nothing is downloaded or sampled from other work.

The ambient loops are synthesized by `generate-assets.ts` (seeded, so re-running it writes identical bytes). Regenerate them from the repository root with `node apps/web/src/audio/generate-assets.ts`. They are mono, 16-bit, 11025 Hz, 8 seconds each, and loop without a seam.

The chime, tick and pop cues are synthesized live with oscillators in `backend.ts`, so they have no files.
