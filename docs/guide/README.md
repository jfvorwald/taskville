# Taskville user guide

Taskville is a local 3D city that shows your coding agents at work. These pages cover getting it running, pairing your browser, answering prompts, what Taskville stores and shows, the agent-team view, and fixing problems.

Start with [install](install.md). It takes a few minutes on a machine with Node and pnpm.

| Page | Read it when |
| --- | --- |
| [Install and first run](install.md) | You are setting Taskville up for the first time |
| [Pairing and answering prompts](pairing-and-prompts.md) | You open the browser, or an agent is waiting for you |
| [Privacy](privacy.md) | You want to know what is recorded, where, and how to hide code |
| [Agent teams](agent-teams.md) | You use Claude Code agent teams or subagents |
| [Troubleshooting](troubleshooting.md) | Something is off; each `taskville doctor` check maps to its fix here |
