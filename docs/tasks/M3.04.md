## What was built

Six work areas as procedural cuboids on a 3 x 3 grid of 10 m cells, a plaza in the center cell, streets on the cell borders, a street graph with plaza anchors and four workstation slots per area, lamps and trees (instanced), and a fixed orthographic isometric camera fitted to the canvas. `CityRoot` now renders `<CityScene />` instead of the scaffold grid (the only edit outside the Owns paths: `apps/web/src/city/index.tsx`).

## Interfaces for M3.05 (agents), M3.06 (navigation), M3.07 and the overlays

Import from `apps/web/src/city/layout/index.ts`. It is pure TypeScript (no React, no three.js).

- Units are meters. x east, z south, y up, ground top at y = 0. Ground slab is x, z in [-17, 17].
- `CITY_LAYOUT: CityLayout` is the one immutable instance (`buildCityLayout()` builds it, deterministically).
  - `areas: WorkAreaLayout[]`: `{ id, name, footprint: { cx, cz, halfX, halfZ }, height, anchorId, slotIds }`. Ids are the engine's `WORK_AREAS` (`dispatch`, `workshop`, `test_lab`, `review`, `security`, `archives`); a test fails if they drift. Order is stable.
  - `slots: WorkstationSlot[]`: `{ id: "<area>:<0..3>", areaId, index, x, z, facing, nodeId, anchorId }`. Four per area, in a row 0.9 m south of the building's front (south) wall, 1.2 m apart, ordered west to east. `facing` is a yaw (radians) such that `(sin, cos)` points at the building. `nodeId` is the slot's own graph node (kind `slot`); `anchorId` is the street node it hangs off (also the area's `anchorId`).
  - `graph: { nodes: NavNode[], edges: NavEdge[] }`: undirected, each edge stored once, `length` in meters. Node kinds: `junction` (street crossing), `street` (every 5 m along a street), `plaza` (center `plaza:center` and doors `plaza:n|s|e|w`), `slot`. Plaza nodes are the natural safe stops for needs-you agents. `plazaNodeId` is the plaza center, the default start.
  - `plaza`, `streets` (`{ axis, at, from, to, width }`), `bounds`, `props: { lamps, trees }`.
- Helpers: `findPath(layout, fromId, toId) -> { nodeIds, length } | null` (Dijkstra), `reachableFrom(layout, id) -> Set<string>`, `nodeById(layout, id)`. M3.06 plans over these or over `graph` directly; slot reservation and spacing are M3.06's.
- Camera: `CITY_CAMERA`, `cameraPosition`, `fitZoom(viewport, cam, layout)`, `projectToScreen(point, zoom, viewport, cam)`. M3.03's world-labels slot can use `projectToScreen` (with the zoom the canvas actually uses: `fitZoom` for the canvas size) to place DOM labels over world points, or read the live camera from R3F. `CityCamera` makes its camera the R3F default camera (`makeDefault`).
- Rendering: `CityScene` (props `layout`, `palette`) from `apps/web/src/city/buildings/index.ts`. `buildingParts(area)` and `windowSites(layout)` are the pure part lists. Agents mount beside `CityScene` in `CityRoot` with a one-line edit.

## Notes

- The mounting edit is `apps/web/src/city/index.tsx` only. M3.05's mount will land in the same file; the lead resolves that conflict (both are one import and one element).
- The scene root's ambient light is left alone; `CityScene` adds one directional light. No shadow maps yet (the architecture says soft shadows; that needs the `shadows` prop on the shared `Canvas`, so it is a follow-up for whoever owns `SceneRoot` or the theme tickets).
- Palette: `DEFAULT_CITY_PALETTE` is a neutral set; the theme tickets pass their own `CityPalette` to `CityScene`. Materials are shared, one per palette entry.
- Instancing: all windows are one instanced mesh; lamp poles, lamp heads, tree trunks and crowns are one each. Buildings are a few unit boxes each (not instanced; one-offs).

## Lessons

- The scaffold e2e script builds before it tests, but `playwright test` on its own serves a stale `dist`; after a visual tweak rebuild first or the screenshot will not change.
- Port 4817 is fixed in the scaffold's Playwright config and is shared by every worker running e2e at once; `E2E_PORT=<free port>` avoids a collision. One smoke run also failed its 5 s `scene-root` wait while the machine was busy with parallel workers, and passed on the rerun (flake, one line).
- With the default ACES tone mapping and ambient light 1, dark albedos (about #2b3340) render almost black; the ground needed mid-grey albedos to read against the dark scene background.
