- **Lessons:**
  - Reducer state keyed by producer-supplied IDs must never be read as `map[id]`: an ID such as `constructor` finds `Object.prototype.constructor`, and an assignment with `__proto__` changes the prototype. Use `Object.hasOwn` to read, and spread with computed keys or `Object.fromEntries` to write; prototype-named IDs belong in the property-test pools.
  - Ingest order and occurrence order disagree under async hooks (S-2). Every "latest" rule (primary session, last seen, reopening an ended session) had to compare instants, and protocol timestamps carry offsets and arbitrary fractional digits, so text comparison and `Date.parse` are both wrong. A pure comparator in `entities/time.ts` does it.
  - Two parallel tickets that both add a dependency and an `exports` entry to the same package.json conflict on every rebase, and CI does not run on a conflicted PR, so a quiet CI can mean a conflict. Check `gh pr view --json mergeStateStatus` early.
  - roborev kept finding edge cases in the bounded tool-call projection, three rounds in a row. Writing down the bounded-state contract (what is counted when, and what is forgotten) before coding would have saved two rounds.
