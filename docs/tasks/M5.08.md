Fixes:
- B1: `CrewHighlight` wraps the renderer `render` so the dim and the lift are put back just before each draw, after every frame callback, whatever order SubagentCrew or AgentBlock registered in (no useFrame priority, so auto-render stays). The lift is taken off and put on again (idempotent), so it cannot accumulate. - S2: tethers are `frustumCulled={false}` and recompute line distances only when an end point moved. Tethers are a `Tether` component keyed by from/to, not "a|b" strings.
- S1: no scene traversal while nothing is active (idle early return); rings and tethers share one id-to-group walk per frame.
- Nits: heuristic unknown reads "Unknown"; a return to the default view (Reset) ends an ease; `CrewHighlight` gets `reducedMotion || mode === "history"` in `city/index.tsx`; fade copies set `depthWrite = false`.
