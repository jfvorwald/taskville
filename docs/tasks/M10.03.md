## What changed

- `tokens.css`: `--tv-ok`, `--tv-fail`, `--tv-running`, `--tv-mono`, `--tv-rule`.
- Shell: panel is `min(440px, 100% - 32px)` wide and `100% - 32px` high. The panel no longer scrolls; the crumbs, header and tab list stay in view and only the tab slot scrolls. Header facts sit on one line separated by spacing, status is a dot plus the word, the current file is in `--tv-mono`.
- Crew: thread style with a status node per child (running hollow `--tv-running`, finished filled `--tv-ok`) and a two-line clamped result with a "Show more" button that appears only when the text is longer than two lines. Result text is still plain text.
