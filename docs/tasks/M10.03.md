## What changed

- `tokens.css`: `--tv-ok`, `--tv-fail`, `--tv-running`, `--tv-mono`, `--tv-rule`.
- Shell: panel is `min(440px, 100% - 32px)` wide and `100% - 32px` high. The panel no longer scrolls; the crumbs, header and tab list stay in view and only the tab slot scrolls. Header facts sit on one line separated by spacing, status is a dot plus the word, the current file is in `--tv-mono`.
- Crew: thread style with a status node per child (running hollow `--tv-running`, finished filled `--tv-ok`) and a two-line clamped result with a "Show more" button that appears only when the text is longer than two lines. Result text is still plain text.
- Breadcrumb: no Family navigation when the family path holds only the agent itself (the header already names it). Three older tests in `shell/AgentPanel.browser.test.tsx` that pinned a single crumb for a lone agent were updated to the new rule (lead decision).
- Files: directory muted, file name in `--tv-mono`, edit count right-aligned; Windows paths split on the backslash.
- Review-fix round:
  - Short viewport: the tab slot keeps a 120 px minimum and the panel scrolls as the fallback. The slot has padding (with a matching negative margin) so focus rings are not clipped.
  - Focus: when the parent crumb removes the breadcrumb, the heading (`tabIndex` -1) takes focus.
  - Header facts shrink with a per-item ellipsis (the role first), so the status stays visible. The urgent color has a `#e5484d` fallback. The header file truncates at the start, with the full path in a `title`.
  - Crew: status nodes have a text equivalent (Working, Idle, Finished, Unknown). Runs of blank lines are collapsed in the summary, and the toggles are named "Show more of <child>'s result" and "Show less of ...".
  - Host: the wider sidebar slot is scoped to the agent panel with a `data-overlays` attribute on the slot, so the action card keeps 360 px.
  - Themes: `--tv-ok` is published by every theme (the controller never removes a property), darker on aero day, solarpunk and steampunk day, and `#5fb98a` on the dark surfaces. `--tv-ok` is a known optional token in the theme contract.
