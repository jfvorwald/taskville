- **Design notes:**
  - `mask.ts` calls the engine's `redactText` and `redactJson` by relative path instead of copying rules. `inputMaskSpans(toolInput, text)` maps every span `redactJson` finds in a string to the displayed (JSON-escaped) text by the length of the escaped text before it, and every sealed non-string value to its whole range. If the displayed layout cannot be mapped and `redactJson` found anything, the whole input is one span (fail closed). `{ command }` alone stays precise.
  - `markControls` shows invisible and reordering characters as `<U+XXXX>` after the spans are found on the raw text, so offsets follow the engine; `visibleControls` is also applied to the agent name, session id, tool name, project id, working directory and reason.
  - `useCardTarget` keeps the last target until the selection changes and marks it `stale` once the request left attention; a stale card still open is shown as closed, so it offers no decision.
  - Exact input: aborted on unmount and selection change, 10 s timeout, the body must be for the requested request, Allow waits 500 ms after the input renders and, if the box overflows, until it is scrolled to the end ("Input: N lines"). Commands: 10 s timeout; a retry after a network failure, a timeout or `command_in_flight` reuses the idempotency key; a decision is "sent" only when the command status is `delivered`.
  - A 410 on the input or `request_expired` from decide gives the open-session-only variant with "The hold ended. Answer in the terminal, or open the session." (wording shared with the M4.10 e2e); a recorded state outranks it.
  - One persistent `role="status"` line takes focus after a send; after a reveal focus moves to the next reveal button or the revealed text. The working directory falls back to the session's recorded `workingDirectory`, else "unknown".
