## What changed

- `EvidenceStore.fitArchiveEvidence` checks each incoming body, in order, against the archive budget left (stored bytes, no sharing between bodies, so the total never passes the cap). Bodies that do not fit are dropped and counted in `evidenceDropped`; smaller ones after them may still be stored.
- `archiveEvidenceFull` no longer takes an `excluding` list. Room from archives due for pruning is credited only after `deleteArchive` succeeded for them; a failed deletion credits nothing, so the new evidence is dropped and counted.
- `deleteArchive` takes `{ keepPointers: true }`: bodies and usage go, pointers stay, so a done archive whose row deletion then fails reads its bodies as evicted ("details no longer stored"). The importer removes the pointers once the row is gone.
