## What changed

- Migration V3 (`apps/engine/src/storage/migrations.ts`), additive: `otlp_cost` (one row of totals per agent, CHECKed non-negative and length-bounded) and `otlp_seen` (SHA-256 digests of counted data points). V1 and V2 untouched.
- `apps/engine/src/storage/otlp-cost.ts` (`SqliteOtlpCost`, via `Storage.otlpCost()`).
- `registerOtlpRoutes(app, { storage })`: `CostLedger` loads its totals from the store at construction, writes each changed agent through, and runs each export in one transaction. `serve.ts` passes `engine.storage`.
- Dedupe identity: metrics are session, metric name, sorted attributes, `timeUnixNano`; logs are session, event name, sorted attributes, `timeUnixNano`. Points with no (or zero, or non-integer) `timeUnixNano` are never deduplicated. Without a storage the same identities are held in memory.
- Growth bound: totals are one row per agent (capped by `MAX_LEDGER_AGENTS`, 10,000). Identities are stored as 64-hex digests only, and only the newest `MAX_SEEN_DIGESTS` (200,000) are kept, pruned oldest first on insert, so a re-delivery older than that window would count again.
- Temporality unchanged: every point is a delta.
- Retro: `Snapshot.agentCost?`, `## Tokens and cost` in `docs/retros/TEMPLATE.md` (after Plan versus actual, before the written sections), rows sorted by cost then ID, a Total row, "not measured" when empty.
