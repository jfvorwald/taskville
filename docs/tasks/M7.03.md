- **Lessons:**
  - The engine's SSE framing is Hono's `writeSSE`, not an engine function, so it cannot be imported without Hono; the Worker carries a minimal equivalent in `deploy/staging/src/sse.ts`, checked byte for byte against Hono by the `sse-framing` test.
  - The engine's `PAGE_CSP` lives in a module that reads files, so it cannot be imported either; the Worker holds a copy and `security-headers.test.ts` compares it to the engine's string. `timelines/position.ts` has no imports, so the Worker reuses it directly.
  - The demo run is built when the module loads and its timestamps are shifted once per isolate, at its first demo request, because a Worker's clock reads a fixed time outside a request. Shifting every timestamp of a state gives exactly the state and hash a replay of the shifted events gives (checked for several shifts), so the shift is a string rewrite of prebuilt JSON, not a second run.
  - The contract test requires 2xx for unknown ids on evidence, timelines and the agent feed, where the engine answers 404, so staging answers with explicit empty results. Cost answers like the engine: 404 `no_cost`.
  - Agent feeds are open and empty, and evidence bodies are empty: the tool call tracker lives in `apps/engine`, outside what a Worker can import. The demo's tool calls are therefore not visible on staging.
  - Commands are validated like the engine's strict schema, then refused 410 `request_expired` (400 `history_context_rejected` from history, 404 `unknown_project`), because no request is ever held on staging. `session.open` gets the same refusal, never a success.
  - The staging banner and release ID live in the client, which M7.03 does not own (`apps/web`); the Worker serves `/health` with `release: { id, version, environment }` for it, and `/pair` for the Not paired screen to link to.
  - Adding wrangler made pnpm 12 require `allowBuilds` for `esbuild` and `workerd` in `pnpm-workspace.yaml`, and moved some peer suffixes in `pnpm-lock.yaml`.
  - `account_id` in `wrangler.jsonc` is copied from jaqstudios (same account and zone).
