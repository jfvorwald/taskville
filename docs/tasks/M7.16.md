## Lessons

- A new field in a file whose tests pin the exact key set (`engine.json`) needs that old assertion updated by the test-writer in the same ticket; the red phase should list such tests.
- The vitest `--project` filter takes paths relative to the project root (`test/...`), not the repo root.
- `appendFileSync` types accept only a string `flag`; for O_NOFOLLOW use `openSync` with numeric flags.
- Persisted per-agent telemetry has no milestone key, so a retro cost section built from it is machine-wide unless the schema grows one.
