- **Lessons:** The mapper reports two signals per line, both from its single parse: `LineResult.cwd` (the raw cwd of any non-malformed line that carries one, escaped keys included) and `LineResult.sessionCwd` (the raw cwd used for the `session.started` emitted on that line, set only there). The importer drops its substring shortcut and second parse. The file is validated by the first cwd any line reports (outside the root: skip as `outside-root`; none within the allowance: skip as `no-cwd-in-allowance`), and every `sessionCwd` must be inside the root. Other lines are not re-checked, since a session's cwd can legitimately change. Before validation the only limit is 5,000 lines or 16 MiB; the 1,000-event flush no longer rejects an unvalidated file. `createTranscriptImporter({ onSkip })` reports the reason once per skipped file, and `counts.skipped` is kept. A rejection after a yield stops the file and returns counts to the last yield; an abort on an unvalidated file restores its read, imported and malformed counts. Lead decision 1: `session.started` is unchanged (once per session, `{}` when the first line has no cwd), rather than deferring it or emitting a second one. Lead decision 2: the lead amended the F3 assertion in `session-cwd.test.ts` (the 1,000 cwd-free lines test) to check that no event carries an outside working directory, because with decision 1 no event carries the root there.
