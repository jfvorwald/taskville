## What was built (`apps/web/src/city/agents/`)

- `AgentsLayer` renders one `AgentBlock` per `AgentView`. Mount it inside `CityRoot` with the store's agents mapped to `AgentView` (not mounted yet: no data source on this branch).
- Block humanoid from shared box geometry (`resources.ts`); materials cached by color. No allocation per frame: the frame loop writes transforms into refs and a reused `Pose`.
- Stable colors (`identity.ts`): FNV-1a of the identity key. Subagent body by `agent_type`, trim by parent; teammate/lead trim is the team scarf color.
- Labels: `agentLabel` (name cleaned of control and bidi characters, capped at 24; status from attention then activity). `buildLabelEntries` gives M3.03 the text plus a live world anchor; `AgentsLayer onLabels` hands them over and turns the local sprite fallback off.
- Work loops (`workLoop.ts`): hammer (Workshop), beaker (Test Lab), pages (Archives); reduced motion freezes the pose.
- Sizes (`scale.ts`): subagents 0.6 per generation, floor 0.3.
- Position input is `AgentView.placement`, a mutable `{x,y,z,heading}` that M3.06 navigation updates in place.
