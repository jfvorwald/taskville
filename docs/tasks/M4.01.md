## Project switching

It was small and contained. `useDataSync(projectId)` already restarts its sync loop (and `store.reset(projectId)`) when its `projectId` changes, so the only change is where the id comes from: `projectSelection` in `apps/web/src/data/project.ts` instead of a constant. No change to `store.ts`, `sync.ts` or `react.ts`. The city selection is now cleared on a switch (`OverlayRoot.wiring.browser.test.tsx`: cleared on a change, kept when the same project is chosen again). Not verified in a browser: that the 3D scene itself redraws cleanly across a switch. Because there is no project switcher yet, a chip is the only way into another project, so the header shows an interim "Back to Unsorted" control while away (added after roborev 5812 finding 2); a real project list/switcher is a separate ticket.
