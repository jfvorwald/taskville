### Interface for the implementer (`apps/web/src/history/ui/crew-bars.tsx`)

```ts
export interface CrewRun {
  agentId: string;
  parentId: string;          // latest parentAgentId from a registration
  name: string;              // displayName
  startSequence: number;     // ingestSequence of first agent.registered
  startedAt: number;         // receivedAt ms of that event
  finishedSequence?: number; // ingestSequence of agent.finished; absent = running
  finishedAt?: number;       // receivedAt ms of agent.finished
}
export function crewRuns(events: readonly StoredEnvelope[]): CrewRun[]; // kind "subagent" only
export function CrewBars(props: {
  runs: readonly CrewRun[];
  parentId: string;
  range: { first: number; last: number };
}): JSX.Element | null;
```

Behavior the tests pin:

- Only runs whose `parentId` matches are drawn; no runs gives no bars. Bars sit in a `role="group"` named like "Subagent runs"/"Crew".
- Each bar is `role="img"` with `data-state="finished"` or `"running"`. Horizontal scale is by sequence: left = (startSequence - first) / (last - first) of the group width; right likewise for `finishedSequence`, or the group's right edge when running (open-ended).
- Accessible name: `<name>`, the start as `new Date(startedAt).toLocaleString()`, then `ran <N>s` (whole seconds, rounded) when finished or `running` when open.
