## What changed

- `apps/engine/src/commands/open-session.ts` (new): `openSession(request, { config, execFile })`, result and dependency types, and `defaultExecFile` (promisified `node:child_process.execFile`) for M4.03 to pass in. Copy-only when `config.sessionOpener` is null; otherwise `renderOpener` then `execFile(file, args, { shell: false, windowsHide: true })`. Only `sessionId` and `cwd` are read from the request, so a template on the request is ignored. A rejected value gives `invalid-value`; a spawn error gives `spawn-failed` with only the error code in the message.
