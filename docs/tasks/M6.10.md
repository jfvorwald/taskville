## Green round 2

`recordedTarget.ts`: a walk back from the bisected head position is capped at 64 moments; if it finds no request-opening moment for the selected agent in that span, the lookup uses a per-agent index (request-opening moments by agent, built once per moments array in a WeakMap, rebuilt if the length changes) and bisects the agent's entries by sequence. The capped walk keeps the first call on a large list cheap (the earlier work-bound test has no warm-up). An agent whose first request has not opened by the head gets null.
