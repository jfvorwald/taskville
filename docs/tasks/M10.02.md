- **Design notes:** `live/logbook.ts` holds the pure text rules (state, sentence, duration, secondary line, turn time). Collapsed Details stay mounted with the `hidden` attribute, so textContent-based tests still see the recorded text. Row size estimate is 64 px (collapsed entries are about 62 px), and entry line heights are whole pixels because the virtualizer rounds measured heights.
- **Review-fix round:** a sentence caps its variable part at 120 characters with an ellipsis, never splitting a surrogate pair (`cap`, `capLine`); the full value stays in Details. A failed or unfinished Edit, Write or Read reads "Edit failed: f", "No result for edit of f" and so on, while Bash keeps "Ran". One `callState` feeds the node, sentence, secondary line and default-open, so an Agent or SendMessage whose result says `success: false` is Failed everywhere. Default-open is decided once per entry: a newer failure opens, an older one stays open until the reader closes it. Toggling Details pauses follow and holds the toggled row's toggle at its screen position until the details settle or the view moves. Each node holds a `[data-glyph]` shape (check, cross, ring, dash, alert). The Details toggle is named by itself plus the sentence. The turn divider has an `aria-label` with its time. Read and Search groups use the same Details toggle (their Expand control, pager and list sit inside; an open group also names its first five members), keep their open state when they gain a call, and split at gaps over 2 minutes. Durations from 1 s read as seconds with one decimal; negative ones are hidden. The needs-you ring uses `var(--tv-needs-you, #e5484d)`. A SendMessage to an agent ID leaves the ID out of the sentence, so the recipient chip stays the only control named for that agent.
- **Needs-you matching limitation:** a permission request records its tool name, not a call. One running call of that tool takes the needs-you node. With two or more (or one inside a group) the call cannot be told, so the request becomes its own last entry "Needs you: <Tool>" and no call is marked. Groups are never marked. A request whose tool has no running call adds no entry; the action card at the top of the tab still shows it.
- **Lessons:** when a ticket flips a default from expanded to collapsed, grep every test that reads a card body, not only the ones that click an Expand control. A render that reads a body for display keeps it hot in the evidence cache, so read only what is requested.
