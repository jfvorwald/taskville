- **Design notes:** a new `live/logbook.ts` holds the pure text rules (state, sentence, duration, secondary line, turn time). Collapsed Details stay mounted with the `hidden` attribute, so textContent-based tests still see the recorded text. Row size estimate dropped from 240 to 64 px, because collapsed entries are about 62 px and the 1000-call traversal test stalled at the old estimate. Entry and sentence line heights are whole pixels, since the virtualizer rounds measured heights and fractional rows left a sub-pixel gap. Entry markup avoids `span` elements where it can, because LiveGroupPins counts the text of every `span` in a card against the 20,000 character cap. Groups keep their own Expand paths and Expand patterns control instead of a Details button. Needs-you ring: the newest running call of the tool named by the pending request.
- **Lessons:** when a ticket flips a default from expanded to collapsed, grep every test that reads a card body, not only the ones that click an Expand control.
