Each `<name>.expected.json` holds the hand-written per-line result of a batch ingest: `{ line, sourceEventId?, status, ingestSequence?, of?, code?, path? }`, plus `knownProjects` (`demo`, `unsorted`), `startHead` (1, the `project.created` event), `after` (fixtures ingested first), and a summary. `ingestSequence` assumes freshly added projects.

`loader.ts` (Node built-ins only): `EVENT_FIXTURES`, `parseJsonl(text)` (contracts/events.md JSONL rules: blank and `//` lines skipped, 1-based file line numbers, malformed lines reported, CRLF accepted), `loadFixture`, `loadEvents` (throws with `name:line` on a malformed line), `loadExpected`, `fixturePath`, `FIXTURES_DIR`. Engine and CLI tests import it by relative path, e.g. `../../../fixtures/events/loader.ts` from `apps/engine/test`.

## Forced extra path

`packages/protocol/test/event-fixtures.test.ts`: Vitest only discovers `packages/*/test` and `apps/*/test` (root `vitest.config.ts`), so the golden test lives in the protocol package, which is also what the fixtures validate against. It contains a small reference ingest model (validation, producer policy, project registry, dedupe and conflict on the idempotency key) that must reproduce each expected file line for line.

## Notes for the engine and CLI tickets

- A line that is not valid JSON is expected as `invalid_envelope` with no `sourceEventId` (line 8 of `invalid.jsonl`). events.md does not name a code for it; this is the fixture's choice.
- `duplicates.jsonl` line 8 resends `dup-02` with reordered keys and spaces and expects `duplicate`: canonical content hashing (#6) must ignore key order and whitespace.
- The reference model checks producer policy before `unknown_project`; each invalid line has exactly one problem, so the fixtures do not fix that order.

## Lessons

- The quickstart already pinned the basic fixture's counts (12 accepted, two agents, one running), so the fixture had to be designed backwards from documented CLI output.
- An expected-results file is only a golden if something independent reproduces it: the expected statuses were written out by hand, and a small reference ingest model in the test must agree with them line for line, which a deliberate mutation confirmed.
