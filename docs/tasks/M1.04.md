- **Lessons:**
  - Agent teams behave differently in each display mode. In-process teammates share the lead's `session_id` and carry `agent_id`. Split-pane teammates are separate sessions with no `agent_id`, and their permission prompts fire **no `PermissionRequest`** (only a lead `Notification` with `worker_permission_prompt`), so the planned permission bridge cannot answer them.
  - The Agent tool now launches subagents in the background by default: `PostToolUse(Agent)` arrives at launch (`async_launched`), and the parent's `Stop` fires while its subagents still run.
  - In-process teammates fire `SubagentStart` and `SubagentStop` on every turn, so `SubagentStop` does not mean the teammate is gone.
  - Interactive sessions emit `SubagentStop` with `agent_type: ""` for internal helper agents that never had a `SubagentStart`, and one fired a `PreToolUse` with no Post.
  - The Edit `tool_response` includes `originalFile`, the whole pre-edit file, which matters for evidence size and privacy.
  - Agent teams do not spawn under `claude -p`, so team spikes need an interactive session (tmux `send-keys`). Interactive runs in a new folder show the trust dialog, and accepting it records the folder in `~/.claude.json`, which the spike did for its throwaway folder.
  - Teammates reported `permission_mode: "auto"` while the lead was in manual mode, which goes against the docs.
