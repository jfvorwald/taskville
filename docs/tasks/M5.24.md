- `live/LiveTab.tsx`: `onVisibleCalls` takes an optional second argument, `outputOnly`. Under privacy, visible Search groups report their first `detailPageSize` (at most 32) calls there; privacy groups of any kind no longer report expanded details in full (their card renders none). With Hide code off the argument is empty and behavior is unchanged.
- `live/ConnectedLiveTab.tsx`: the visible reader builds its wanted set from both lists; `readEvidence` takes the parts to fetch, so `outputOnly` calls request the output part only. The existing cache, queue, retry and obsolete-token paths are reused; nothing is logged.
- Privacy card "and N more": search calls past the cap are never loaded, so their hits are unknown. Each such call without a loaded output or recorded paths counts as one in N, a lower bound. Without this, an 80-call group showed 32 names and no "and N more".
