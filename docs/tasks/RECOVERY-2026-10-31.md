## Independent Codex workflow

Simplest: the owner starts a T3 Code Codex thread for one explicitly reserved issue in its own T3-managed worktree. The integration lead remains the sole owner of main, board, STATUS, LESSONS, merges, and gates. Use model gpt-6.1-sol, medium effort, default service tier. Keep Claude's team off that issue and its Owns paths. A separate thread without worktree isolation can share the root checkout and is unsafe for concurrent writers.

Before starting: reserve the issue with the integration lead, name the worker and owned paths, pin the base commit, and list any shared-file dependency. In T3 choose a worktree workspace, not the shared root. Supply: issue URL, Owns, Done when, baseline, checks, stop time, and instruction to stop at a PR. Handoff must include branch/worktree, HEAD SHA, exact checks, roborev job/outcome, remaining TODOs, NOT RUN items, and blockers. After the worker's final-head report freeze it; the integration lead merges and updates shared records. User independently assigning work must first tell the lead which issue is reserved.

Suggested prompt:

> Own issue <URL> exclusively from <base SHA>, in an isolated T3 worktree. Edit only its Owns paths and necessary tests/report. No subagents. Test first, smallest change. Follow AGENTS.md. Produce one PR and report HEAD SHA, exact checks, roborev outcome, NOT RUN items and blockers. Do not merge or edit shared status. Stop new work at <time>; checkpoint by <time>.

Programmatic T3 handoff is supported: `delegate_task` with `isolation: "worktree"`, role implementation/test/review as appropriate, and target `{providerInstanceId: "codex", model: "gpt-6.1-sol", options: {reasoningEffort: "medium", serviceTier: "default"}}`. Pass a self-contained ticket brief; parent history is not included. Use T3's prepared worktree, never ask the child to create another. Observe completion delivery and cancel tasks being replaced. No delegate was started for this assessment.

Installed CLI help verifies `-C`, `-m`, `-c` and `--json`; for example, from the reserved worktree use `codex exec -m gpt-6.1-sol -c model_reasoning_effort='"medium"' --json "<bounded ticket brief>"`.
