## Interface (`@taskville/adapters/claude-code`)

`mapClaudeCodeHook(payload: unknown, ctx: { projectId, sourceEventId, receivedAt, late }): { events, evidence?, ignored? }`. This is the interface the lead set and that M2.02 (`ClaudeCodeMapper`) already builds against. It is pure (no I/O, clock, or randomness; the package purity test scans it) and stateless.

| Hook | Events |
| --- | --- |
| SessionStart | `agent.registered` (kind `session`, `sourceAgentId` = `session_id`, name = cwd base name or "Claude Code", role = `agent_type` or `main`), `session.started { workingDirectory }` |
| SessionEnd | `session.ended { outcome: reason }` |
| UserPromptSubmit | `session.prompt_submitted` (prompt text never copied) |
| PreToolUse | `tool_call.started { toolCallId: tool_use_id, toolName, filePaths?, summary? }`, plus `activity.started` for known tools; evidence `{ toolCallId, input: tool_input }` |
| PostToolUse / PostToolUseFailure | `tool_call.finished { phase: succeeded / failed, durationMs?, summary? }` (failure summary = first line of `error`); evidence `output` = `tool_response`, or `{ error, is_interrupt }` |
| Stop / StopFailure | `session.turn_ended` / `session.turn_failed { reason }`, then `activity.ended` |
| Notification | `permission_prompt` gives `request.opened { kind: permission, reason: message }` with `correlationId` = `prompt_id`; `idle_prompt` gives `session.idle_prompt`; other types are ignored |
| Elicitation | `request.opened { kind: elicitation, reason: "<server>: <message>" }` |
| SubagentStart/Stop, TeammateIdle, TaskCreated/Completed, `worker_permission_prompt` | ignored, for the crew mapper (#23) |
| PermissionRequest / MessageDisplay / ElicitationResult | ignored (bridge M4 / feed M5 / next session event closes the request) |

- **IDs:** `agentId` is `claude-code:<session_id>` for the main agent and `claude-code:<session_id>:<agent_id>` for a hook with `agent_id`. Envelope `sessionId` is the raw `session_id` (the parent's for subagent hooks). Each event's `sourceEventId` is `<ctx.sourceEventId>:<type>`, and `requestId` is `claude-code:request:<ctx.sourceEventId>`. A ctx `sourceEventId` over 170 characters is ignored, because derived IDs must fit 200. `session_id`, `agent_id`, `tool_use_id`, and `prompt_id` must match `[A-Za-z0-9][A-Za-z0-9_.@-]*` within a length bound, and are refused if the redactor would mask them: ID fields are stored unmasked.
- **Seam for #23:** `attributeHook`, `sessionAgentId`, `subagentAgentId`, `CREW_HOOKS`, and `mapCoreHook` are exported. `claude-code/index.ts` calls `mapCoreHook` and is where the crew mapper plugs in. Session-level hooks carrying `agent_id` are left to #23, so a subagent can never become the owner of its parent's session in the reducer.
- **Late (8.1):** every event carries `late: ctx.late` (the engine overwrites it anyway). A late `request.opened` is still emitted. The reducer records it as expired, so it never opens needs-you (data-model "Requests and commands"). This is the protocol v1 mechanism.
- **Activity (8.1, 8.3):** Edit, MultiEdit, Write, NotebookEdit map to implementing. Read, Grep, Glob, WebFetch, WebSearch map to researching. Agent and Task map to dispatching. A Bash command whose command position runs tests (`pnpm test`, `npx vitest`, `python -m pytest`, `go test`, `cd app && bun test`, ...) maps to testing with `heuristic: true`. Any other tool, including other Bash commands, sets no activity rather than a guess.
- **Untrusted text (L-17/18/29/31/32):** fields are read with `Object.hasOwn`; lookups use `Map`/`Set`/`switch`, never `obj[payloadKey]`. Summaries, names, paths, and outcomes are made well-formed, masked with `@taskville/adapters/redact`, then cut after masking. **`reason` is the exception.** It is passed on unmasked so the engine masks it and records `masked: true` (FR-017). One over 4,000 characters is cut before any secret the cut touches, and the cut text is re-checked so every secret it keeps is still detected.

## For the lead (follow-ups and risks)

1. **Composition:** M2.02 left `serve` without a mapper, pending #22. Wiring `mapClaudeCodeHook` into `ClaudeCodeSource` is in `apps/engine` (not this ticket's Owns).
2. **One prompt, one red state (M4):** a `permission_prompt` Notification names no tool (S-1). Once the bridge exists, its `request.opened` will not merge with the telemetry one under the data-model rule (session + agent + tool). Both now carry what is needed to match: the telemetry request carries `correlationId` = `prompt_id`, and the bridge has the same `prompt_id`. The M4 merge rule should use it. This came from roborev 5076 high, answered with this evidence.
3. **Denied tool calls stay running:** a hook deny or a terminal No fires no PostToolUse (S-1), so the ToolCall stays `running` until something else closes it. The stateless mapper cannot close it. A reducer rule (for example, close running calls of the session on its next turn event) would need a domain ticket.
4. **Shared session_id closes requests:** the reducer closes a session's open requests on the next `tool_call.finished` from the same `sessionId`. Subagents and in-process teammates share the lead's `session_id` (S-2), so a parallel subagent finishing an unrelated call marks the lead's prompt `answered_elsewhere`. This is domain behavior, not changed here.
5. **Session ownership race:** the reducer gives a session to the first agent that names it. If Taskville starts mid-session and the first event it sees is a subagent tool call, the subagent owns the session. Subagent events keep `sessionId` because that is the recorded fact; the domain may want to revisit this.
6. **Redactor gap (low):** the GitHub token pattern does not match after `_` (e.g. `mcp__ghp_...`), because its lookbehind excludes underscores. This is in `src/redact`, not changed here.
7. **Interface limit:** ctx `sourceEventId` must be at most 170 characters, while M2.02's route accepts up to 200. Longer IDs come back `ignored`. The shim sends UUIDs.

## Lessons

- Masking a field before ingest hides the engine's masking metadata. A field that has a `masked` flag (reasons) must reach the engine unmasked. Cutting such a field must not split a secret or strip the context after it (the `@` after a URL password) that the redactor needs to see it. Re-run the redactor on the cut text instead of reasoning about span edges (roborev 5076, 5092, 5100).
- Scanning every argument for `test` misreads option values (`pnpm -C test build`). Parse the command position and skip known value-taking options (roborev 5103, 5111).
- The S-1 server log shows three tool calls with no PostToolUse at all (deny and terminal No). "Missing Post" is the normal path for every denied permission, not a rare race.
