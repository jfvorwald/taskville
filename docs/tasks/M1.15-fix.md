## Change

`packages/demo/src/pace.ts`: `parseDuration` returns at most `MAX_DURATION_MS` (30 days of simulated time, exported) and throws `Invalid duration "...": at most 30 days` otherwise. The check is `!(ms <= MAX_DURATION_MS)`, so `Infinity` and `NaN` both fail. `parsePace` parses its intervals with `parseDuration`, so custom pace intervals are bounded the same way. 30 days covers any demo or soak run (the soak target is 8 hours) and keeps every value a safe integer.

## Lessons

- Bounding a parsed value in the parser fixes every caller at once. The CLI checks from M1.16 had to be added flag by flag, because each command validated its own inputs separately.
