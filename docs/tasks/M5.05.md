(2) Never index a record by a selection id with `byId[id]`; selection ids such as `area:library` or `constructor` are not agent ids, use `Object.hasOwn`. (3) Cycles in recorded parent links are cut once, when the links are built (the member registered first becomes the root), so path, order and Crew all see a forest and agree from every member. (4) The Escape rule `shouldClearOnEscape` is keyed on the Escape key, so the bracket keys reuse it through a synthetic event carrying the real target and `defaultPrevented`; a shared "is this key event free" helper in `city/interaction/escape.ts` would remove that shim. (5) The sidebar slot is `min(360px, 100% - 32px)` wide, so anything inside it with its own margins needs a `min()` width, not a fixed one.
