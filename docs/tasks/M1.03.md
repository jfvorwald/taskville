- **Lessons:**
  - The terminal permission dialog is not suppressed while a PermissionRequest hook holds, so the focus-dependent short hold in ARCHITECTURE section 8.1 is not needed.
  - A terminal Yes leaves the held hook request open until its timeout, and a later hook answer is written successfully but ignored. "Reached a still-open hook response" does not prove a decision took effect.
  - A terminal No closes the hook connection at once and fires no other hook; the socket close is the only signal.
  - In this Claude Code version the default permission mode is labeled "manual mode" in the UI and an unflagged session started in auto mode; spikes must pass `--permission-mode default`.
  - Driving the TUI with tmux: long text followed by Enter in one `send-keys` sometimes left the prompt unsubmitted; send the text, then `C-m` separately.
