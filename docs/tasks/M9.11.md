- **Lessons:**
  - Sample once and you sample a transient: poll for the condition (two agents on break) in a window instead of a single read.
  - A frame-rate sample is only valid on a settled scene: wait for no agent moving for a continuous period, with a bounded deadline, then measure.
  - Poll timeouts cost nothing when they hold early, so size them for a loaded CI box (60 s), not an idle laptop (15 s). The chatter test now also waits on the exact expected line and a few frames after moving the clock.
  - Seeded fuzz cases simulate minutes of walking; give them an explicit timeout (30 s) rather than the 5 s default, instead of shrinking them.
