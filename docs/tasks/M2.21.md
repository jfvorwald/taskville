## Config-driven program paths for the watcher's commands (`rev-parse`, `for-each-ref`, `log`)

- Covered by the guards (they only start a program through a fetch or transport): `remote.<r>.uploadpack`, `ext::`, `core.sshCommand`, `credential.helper`, a `git-remote-<name>` helper on PATH, `url.<x>.insteadOf`, `remote.<r>.vcs`. Each of the first five has a test (scan and explicit fetch). `GIT_SSH`, `GIT_ASKPASS`, `GIT_EXTERNAL_DIFF` and every other `GIT_*` were already stripped.
- Closed earlier: `core.fsmonitor`, `log.showSignature`, `core.pager`.
- Not reachable by these commands: hooks, diff/textconv/filter drivers (no `-p`, no signature or notes placeholders), `core.editor`, auto-gc, submodules.
