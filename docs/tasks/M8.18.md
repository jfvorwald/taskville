- **Lessons:** An in-place rewrite keeps the inode, so identity checks cannot protect a probe-then-import design; validate the content actually imported. The importer now has no probe: one descriptor, and the first cwd-bearing line read during the import must be inside the root. Nothing is yielded before that line is seen, and a file that fills a first batch (lines, bytes or events) without one is skipped, so buffering before validation is bounded at one batch, and a rejected or cwd-less file has its counts restored and is counted skipped. Later lines are not re-checked (scope stays per file, by its first cwd), to avoid parsing every line twice. The mapper never evicts `sessions`: a new session at the 50,000 cap is malformed, so no known session or subagent registers twice; `pending` still evicts. The dev and ino compare was dropped as redundant with one descriptor.
