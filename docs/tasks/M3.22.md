## Change

`CityRoot` (`apps/web/src/city/index.tsx`) already computed the settings-resolved `reducedMotion` for `CityAgents`. It now passes the same value to `Celebrations` and `InteractionLayer`, which fall back to the raw `prefers-reduced-motion` media query when the prop is undefined. The Settings choice (on, off, system) now reaches celebrations and the building fade.

This also resolves roborev 5518 medium 1 (M3.13).
