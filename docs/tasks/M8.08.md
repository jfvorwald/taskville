## What changed

- `apps/cli/src/commands/import.ts`: `importCommand(io, args)`. The kind (`git` or `transcripts`) is checked before the engine is contacted. Project and root default from the deepest configured root that contains the current directory (`GET /v1/projects`); `--project` and `--root` override. It then runs `POST /v1/imports` and polls `GET /v1/imports/:id` every `io.importPollMs` (default 500 ms) until a terminal status. It prints progress lines and a final summary (counts, malformed by code, truncated notice), or only the final record with `--json`. Exit is 0 on done and 1 otherwise. Engine codes `root_not_configured`, `import_running`, `unknown_import_kind` and `engine_closing` (matched by raw string) get plain messages. Output is counts and codes only, never source text.
- `apps/cli/src/main.ts`: `import` in the COMMANDS table and in USAGE.
