- **Lessons:**
  - hono `serveStatic` follows symlinks out of the web directory and serves dotfiles, and `app.request("/../x")` normalizes `..` away before the app sees it, so the existing traversal test passed vacuously. A real-socket test with a raw request line is the honest check; the static handler is now ours (`apps/engine/src/http/static.ts`).
  - A hidden-file rule on the request path is not enough: a public-looking symlink inside the root can resolve to a hidden file. Check the resolved path too.
  - Mounting a static handler with `app.get("*")` adds a route-table entry that the CLI route-table test pins; `app.use` keeps it out.
  - Clearing the pairing code from the address bar before the exchange means a network failure cannot be retried from the page; the notice asks for a new link instead of offering a retry that cannot work. A link pasted into the same tab only fires `hashchange`, so the page listens for it.
  - An async check that can delete state (a 401 on a stored session) must delete only what it checked, and a superseded attempt's result must be dropped. The second panel found this after a fix added a second way to start an attempt.
  - Vite types CSS Module class lookups as an index signature, which `noUncheckedIndexedAccess` turns into `string | undefined`; the web package turns that one flag off.
  - Vitest Browser Mode needs the Chromium revision that matches the installed Playwright (`pnpm exec playwright install chromium` after a Playwright bump). The first browser run after the install failed one test once with a React context error and passed on the next run; I did not find the cause.
  - Machine load average reached 61 while reviews and other workers ran, and unrelated 5 s timeouts appeared in `pnpm check`. They pass alone.
