- **Lessons:**

  - A bundled CLI breaks every `new URL("../..", import.meta.url)` in the sources. The release build rewrites the four such paths and fails if a rewrite stops matching or a new module uses `import.meta.url`.
  - vite ships rolldown, so bundling the CLI and engine needed no new dependency. Resolve it from vite's own location under pnpm.

  - A test runner's `NODE_ENV=test` leaks into child builds: pin `NODE_ENV=production` for any build whose output is shipped.
  - The agent guard blocks some shell commands that mix test paths with file writes; the Write and Edit tools are the reliable route for source files.
