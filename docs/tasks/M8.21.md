- **Root cause:** a session whose first line had no cwd registered with `session.started {}`, and only the registering line's cwd (`sessionCwd`) was checked, so its later outside cwd was never validated; a non-session line could validate the file on its own.
- **Fix:** the mapper's per-session state gains one flag, `awaitingCwd`, set when a session registers without a cwd. The first later line with a cleaned cwd clears it and reports `LineResult.sessionFirstCwd` (the cleaned value, the one that would be stored). The importer checks it with `sessionCwd`; an outside value stops the file at that line as `outside-root`. Later cwd changes are not checked, so an honest session may still move.
- **Lessons:** when a check is keyed to the event that carries the value, cover the case where the event carried no value and the value arrives later. Implementation by the implementer; report written by the lead after the guard hook blocked the implementer's report write.
