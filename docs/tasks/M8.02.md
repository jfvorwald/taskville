## What was built

- `packages/adapters/src/claude-code/transcripts/index.ts`: pure mapper. `createTranscriptMapper({ projectId })` gives `mapLine(raw, lineNumber)` and `finish()`; also `transcriptSlug(root)` and `TRANSCRIPT_SOURCE_ID = "claude-code:transcript"`. It reuses the hook adapter's ID helpers (`sessionAgentId`, `subagentAgentId`, `isHookId`), text cleaning and event shapes, so imported events match live ones apart from `sourceId` and `provenance: "imported"`.
- `apps/engine/src/importers/transcripts/index.ts`: `createTranscriptImporter()`, kind `transcripts`. Streams each file with `readline`, yields a batch per 500 lines and one at the end of each file, checks the abort signal before each file and after each batch, and reports progress after each batch.

## Slug rule

The project directory is `<config dir>/projects/<slug>`, where the slug is the configured root with every character outside `[A-Za-z0-9]` replaced by `-` (`/tmp/spike-s2/proj` becomes `-tmp-spike-s2-proj`). The config dir is `CLAUDE_CONFIG_DIR` if set and non-empty, else `~/.claude` (from `os.homedir()`, which follows `HOME`). Only regular files ending in `.jsonl` directly in that directory are read; other files, symlinks, subdirectories and other slugs are ignored. A missing directory gives zero counts. Files are read in name order.

## Behaviors chosen (from the red tests and where they were silent)

- Outcomes per line: `mapped` when the line produced events; `skipped` for blank lines, known non-conversation types (`summary`, `system`, `file-history-snapshot`, `queue-operation`, `progress`, `custom-title`, `last-prompt`) and conversation lines that yield no events (assistant prose without a tool call or turn end); `malformed` for bad JSON, non-object JSON, unknown `type`, and user or assistant lines missing a valid `sessionId`, `timestamp` or `message.content`.
- Session events appear on the first mapped line of a session: `agent.registered` (kind `session`, like the hook adapter) then `session.started` with `workingDirectory` from `cwd`.
- Sidechain lines with a valid `agentId` belong to `subagentAgentId(session, agentId)`, registered once as a subagent with the main agent as parent. A sidechain line without a usable `agentId` stays with the main agent. Sidechain prompts and turn ends produce no prompt or turn events.
- Tool calls pair by `tool_use` id; a result lands on the agent that started the call, and a result with no start still maps. `is_error: true` gives phase `failed`. No `durationMs` (the transcript lines carry no duration field the mapper trusts).
- A user line with string content or a text block is a prompt, unless `isMeta` is true.
- `session.turn_ended` on an assistant line whose `stop_reason` is `end_turn`. `session.ended` is emitted by `finish()` (at the time and line of the last turn end) only for sessions whose last activity was a turn end and only when the file's last line parsed; a truncated final line means no inferred end. The importer calls `finish()` per file and skips it when cancelled mid-file.
- `sourceEventId` is `transcript:<session>:<line>:<index in line>:<type>` (and `transcript:<session>:ended`); `sourceSequence` is the line number; `occurredAt` is the line's timestamp. Mapper state is per file, so a session id repeated across files (a resumed session) yields the same ids for the same line numbers and the runner's dedup applies.
- No `activity.*` events are produced (not listed in the design); only the event types the design names.
- Evidence: input and output are redacted with `redactJson` first, then strings are cut to 8 KiB and a value still over 32 KiB becomes `{ truncated: true, preview }`. Redacting before cutting means a cut never leaves part of a secret. Prompt and assistant prose never appear in events or evidence.
- Tool summaries use a short local key list (description, command, file path, pattern, url, query) instead of the hook adapter's private `toolSummary`, which is not exported and lives outside this ticket's Owns.
