## What was built

- `packages/adapters/src/claude-code/transcripts/index.ts`: pure mapper. `createTranscriptMapper({ projectId })` gives `mapLine(raw, lineNumber)` and `finish()`; also `transcriptSlug(root)` and `TRANSCRIPT_SOURCE_ID = "claude-code:transcript"`. It reuses the hook adapter's ID helpers (`sessionAgentId`, `subagentAgentId`, `isHookId`), text cleaning and event shapes, so imported events match live ones apart from `sourceId` and `provenance: "imported"`.
- `apps/engine/src/importers/transcripts/index.ts`: `createTranscriptImporter()`, kind `transcripts`. Reads each file with a bounded line reader (`maxLineBytes`, default 8 MiB; an over-long line, including an unterminated last one, is counted malformed and never buffered whole), yields a batch per 500 lines and one at the end of each file, checks the abort signal before each file and after each batch, and reports progress after each batch.
- `packages/adapters/package.json`: new export `./claude-code/transcripts` (a subpath export, not a re-export from the claude-code index, so the engine imports only what it needs). Lead-approved, outside Owns.

## Slug rule

The project directory is `<config dir>/projects/<slug>`, where the slug is the configured root with every character outside `[A-Za-z0-9]` replaced by `-` (`/tmp/spike-s2/proj` becomes `-tmp-spike-s2-proj`). The config dir is `CLAUDE_CONFIG_DIR` if set and non-empty, else `~/.claude` (from `os.homedir()`, which follows `HOME`). Only regular files ending in `.jsonl` directly in that directory are read, opened with `O_NOFOLLOW` so a symlink swapped in after listing is skipped. Slugs collide, so a file is read only if its first `cwd` is the root or inside it (separator-aware); files with no `cwd` or another root are skipped and counted. A missing directory gives zero counts. Files are read in name order.

## Behaviors chosen (from the red tests and where they were silent)

- Outcomes per line: `mapped` when the line produced events; `skipped` for blank lines, known non-conversation types (`summary`, `system`, `file-history-snapshot`, `queue-operation`, `progress`, `custom-title`, `last-prompt`) and conversation lines that yield no events (assistant prose without a tool call or turn end); `malformed` for bad JSON, non-object JSON, unknown `type`, and user or assistant lines missing a valid `sessionId`, `timestamp` or `message.content`.
- Session events appear on the first mapped line of a session: `agent.registered` (kind `session`, like the hook adapter) then `session.started` with `workingDirectory` from `cwd`.
- Sidechain lines with a valid `agentId` belong to `subagentAgentId(session, agentId)`, registered once as a subagent with `parentAgentId` set only when its first sidechain line has a `parentUuid` equal to the uuid of an earlier line holding an Agent or Task tool_use (the agent that made the call); otherwise the key is absent. A sidechain line without a usable `agentId` stays with the main agent. Sidechain prompts and turn ends produce no prompt or turn events.
- Tool calls pair by `tool_use` id; a result lands on the agent that started the call, and a result with no start still maps. `is_error: true` gives phase `failed`. No `durationMs` (the transcript lines carry no duration field the mapper trusts).
- A user line with string content or a text block is a prompt, unless `isMeta` is true.
- `session.turn_ended` on an assistant line whose `stop_reason` is `end_turn`. `session.ended` is never emitted from a transcript (a transcript cannot prove a session ended); `finish()` returns no events.
- `sourceEventId` is `transcript:<file id>:<line>:<index in line>:<type>`, where the file id is the file basename without `.jsonl` (cut to 100 chars with a hash suffix if longer), so two files sharing a session id never collide; `sourceSequence` is the line number; `occurredAt` is the line's timestamp. Mapper state is per file.
- No `activity.*` events are produced (not listed in the design); only the event types the design names.
- Evidence: input and output are bounded first (strings pre-cut to 64 KiB, keys cut to 256 chars and masked with `redactText`, nesting past 32 levels replaced by a marker string), then redacted with `redactJson`, then strings get the final 8 KiB cut (a secret straddling the 8 KiB boundary is masked whole before the cut; one straddling the 64 KiB pre-cut falls past it; a cut inside a run of token characters backs up to the start of that run or at most 128 characters, because the redactor does not match a key glued to preceding letters); a value still over 32 KiB becomes `{ truncated: true, preview }`. `mapLine` never throws: any unexpected error counts the line malformed. Prompt and assistant prose never appear in events or evidence.
- Tool summaries use a short local key list (description, command, file path, pattern, url, query) instead of the hook adapter's private `toolSummary`, which is not exported and lives outside this ticket's Owns.
