## Design

`recordedTarget.ts`: the 64-moment walk back from the bisected head stays as the cheap path. When it finds no retained opening, the fallback no longer steps through the agent's openings. A per-array index (WeakMap keyed by array identity) maps agent to request id to opening moment. The target is the agent's request in the replayed state whose opening moment has the greatest sequence at or before the head. Merged-away openings are never retained, so they are never visited. Results match the old behaviour, including that a merged-away opening does not resolve to its host.
